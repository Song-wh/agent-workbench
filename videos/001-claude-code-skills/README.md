# 001 · Claude Code Skills in 6 Minutes (Build One From Scratch)

[`standup/SKILL.md`](standup/SKILL.md) is the 17-line `/standup` skill built in the video. It reads your git log since yesterday, groups the commits, and writes Yesterday / Today / Blockers - and for Today and Blockers it asks you instead of guessing.

Copy the `standup` folder into `~/.claude/skills/` (every project) or `<your project>/.claude/skills/`, then type `/standup` in Claude Code.
