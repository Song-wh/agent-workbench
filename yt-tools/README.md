# yt-tools

**Uses YouTube API Services.** [Privacy Policy](PRIVACY.md) · [Terms of Service](TERMS.md) · [YouTube Terms of Service](https://www.youtube.com/t/terms) · [Google Privacy Policy](https://policies.google.com/privacy)

A private, single-user command-line tool that manages the owner's own YouTube channels
(Agent Workbench, Blank Spot Files, Filed and Granted):

- scheduled uploads of finished videos the owner has reviewed and approved (with thumbnails and captions),
- daily reading of the owner's own channel statistics and analytics.

It is not a public service and has no other users. To revoke access: https://myaccount.google.com/permissions
